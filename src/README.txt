Eden / BOTW Switch 1.6.0 / Title ID 01007EF00011E000
Распакуйте три папки прямо в Open Mod Data Location. В Configure Game > Add-Ons выберите модули. Отключите дублирующие моды FPS, FXAA, AF и разрешения.
Deck Clarity: фильтрация текстур земли и обход артефакта теней, FXAA выключен в docked. Попробуйте Vulkan, 1x, AF 2x. Возможны лесенки.
Deck Docked 1080p: буфер 1080p в Docked. Внутреннее разрешение может меняться.
Deck Static 60 FPS: статический патч. При менее 60 FPS игра может замедляться. Отключите его, если темп игры падает.
Для сравнения используйте одно сохранение и одинаковый маршрут, дайте кешу прогреться. Тест на реальном Deck не проводился.
