# Zelda BOTW на Steam Deck с Eden

Офлайн-установщик профиля Eden и трёх модов для Switch-версии Breath of the Wild с обновлением 1.6.0. Профиль Full выбирает Docked, Vulkan и масштаб 1×, устанавливает патчи чёткости, кадрового буфера 1080p и статической цели 60 FPS. Производительность на Steam Deck не измерена. Если частота падает ниже 60 FPS, статический патч может замедлить игру.

## Установка

1. Скачай [Zelda-Eden-Setup.zip](./Zelda-Eden-Setup.zip) и распакуй архив в режиме рабочего стола.
2. Закрой Eden и открой `Setup.desktop`. Если KDE попросит, разреши запуск.
3. Выбери профиль. Для отмены повторно запусти программу и выбери «Вернуть прежние настройки».

При наличии ограничения в меню производительности SteamOS подними лимит до 60 FPS и отключи вручную пониженный TDP. Установщик работает с настройками Eden и файлами модов. Патчи и их авторы перечислены в [описании комплекта](./src/README.txt).

## Сборка и запуск из исходников

Требуются Linux и Python 3.8+. Запусти из корня репозитория:

```sh
python3 -m zipapp src -o setup.pyz
python3 setup.pyz
```

Для установки без меню укажи `--mode full`, `--mode balanced` или `--mode restore`. Если конфигурация лежит в нестандартном месте, укажи `--config /путь/к/qt-config.ini`.
